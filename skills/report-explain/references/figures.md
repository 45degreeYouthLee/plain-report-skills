# 图


## 先问：画不画

- **图必须带来新信息。** 文字一句能说清的，不画。
- **一张图只讲一个论点。** 图下一句话写出这个论点。
- **一张图不超过 12 个元素。** 超过就先画 5–8 个元素的总图，细节放第二张图或卡片。

## 内容对应的图

| 内容 | 图 |
|---|---|
| 流程、数据流、调用链 | 从上到下的流程图 |
| 架构、模块层次 | 分层堆叠图（下层给上层干活） |
| 系统各部分怎么连 | 架构图，按下面的线型和形状约定 |
| 多个参与方按时间交互 | 时序图：每方一列，时间向下，箭头写调用名并编号 |
| 有离散状态和转换 | 状态图；要讲"一次运行怎么走"时用回放（`motion.md`） |
| 多种情况、多种失败方式 | 并排的小图，同一画法、同一比例，只有变化的部分着色 |
| 改动前后 | 同一张图两个版本并排；新增用实线加 `--ok` 绿，删除用虚线加 `--risk` 红和删除线 |
| 多个对象比同一组维度 | 表格加状态标签 |
| 趋势、大小、占比 | 折线、排序条形、堆叠条；每个关键数字都配一个图形 |
| 时间安排、里程碑、路线图 | 时间线（见 `pages.md`） |

## 架构图约定

**线型：**
- **实线** = 同步调用
- **虚线** = 异步（队列、事件）、可选，或计划中还没做
- **点线** = 备用路径
- **粗线加强调色** = 这张图要讲的那条路径，每张图只有一条
- **`--risk` 红色加 ✕** = 出问题或被阻断的地方

**形状：**
- **矩形** = 服务或组件
- **圆柱** = 数据存储
- **带三条分隔的矩形或胶囊** = 队列
- **虚线框加左上角小标签** = 边界（进程、网络、信任区）
- **虚线矩形** = 可选或已停用

**还要画：**
- **失败路径，** 不只画正常路径。
- **归属和关键数字：** 用旁注写"单点故障""约 1 万次/秒""由某团队负责"。
- **图例：** 线型和形状有含义时必须有。

## 怎么画

- **画机制，不只画名字。** 画出请求经过缓存的路径，而不是一个写着"缓存"的框。
- **每个箭头都写动作。** 如"写入""每 30 秒轮询"。没含义的箭头不画。
- **画出差别。** 对比方案时，标出每个方案多了或少了哪个框、哪条线。
- **状态用形状、线型和文字区分，** 不只靠颜色。
- **只用一个方向：** 流程图从上到下，宽度不超过阅读栏，手机上不出现左右滚动条。
- **框里的字不超过 8 个。** 解释放旁注；旁注放在所指元素右侧同一行，用细线连接。
- **编号标注：** 要在正文里提到图中某处时，用 ①②③ 标在图上，一张图 3–6 个。
- **跨度上标数值：** 一个数字量的是某段距离（耗时、窗口），就把它标在那段上（尺寸线），不放在图外。

## 画法工具

- **聊天里：** 界面能渲染 Mermaid 时用 Mermaid；不确定能否渲染时，用表格或缩进列表。
- **页面里，流程图和分层图：** HTML/CSS 自动排版（`report-page-style` 的 `.flow` 组件），不手算坐标。
- **页面里，必须精确定位的图**（时序图、带尺寸线的图、回放）：SVG。
  - 先用 ASCII 打草稿，再换算坐标；元素间距不小于 40。
  - SVG 文字不会自动换行。超过 12 个字的标签用 `<foreignObject>` 包一个会换行的 HTML 块；短标签按"每字约 14px 加 32px 内边距"算框宽。
  - 线上的文字下面垫一块背景色矩形，避免和线重叠看不清。
- **画完截图看一眼对齐。**

## 图表细则（数字图）

- **每个标记都承载数据。** 不加图表边框、底色、粗网格线、3D 效果。
- **标签贴着数据，** 水平、左对齐、带单位。少于 5 个系列不要图例，直接标在线上。
- **刻度诚实：** 条形图从 0 开始；并排小图共用一个刻度；按数值排序，除非顺序本身有含义。
- **线宽三档：** 结构 1，数据 1.5–1.75，重点 2.5–3。
- **每张图最多 1–2 条注释，** 放在图注提到的那个点上。

## 图下文字

- **一句结论**（必须）。
- **2–4 句"怎么读这张图"，** 只在图不一目了然时写。
