先全景后细节；扫读；图要带新信息；交互不隐藏；卡片还是表格看内容；布局跟内容量；流程图从上到下；浅底圆角细灰箭头；决策写清牵连、成本、风险、把握；执行 agent 用、云端只答大方向；动画做扩展项。
